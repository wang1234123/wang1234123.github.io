# Yingxue Wang's personal website

Personal academic website with selected research, education, contact information, and a downloadable CV.

Website: https://wang1234123.github.io/

## Files

- `index.html`: website content.
- `styles.css`: layout, colors, and typography.
- `script.js`: navigation and email-copy interaction.
- `assets/profile.jpg`: profile photo.
- `assets/Yingxue-Wang-CV.pdf`: public CV.
- `.nojekyll`: serves this static site directly with GitHub Pages.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. There is no build step.

To update the website, edit the files in this repository, commit, and push:

```sh
git add index.html styles.css script.js assets
git commit -m "Update personal website"
git push
```

Keep the public CV free of private contact details and unpublished research details.
